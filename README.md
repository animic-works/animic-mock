# Animic 画面モック

Animicの画面デザインを確認するためのHTMLモックです。本番アプリのコードではありません。

どちらのページもプロトタイプのフローを登録しています。Figmaの再生ボタンから動きを確認できます。

## 画面一覧

| ファイル | 画面 |
| --- | --- |
| `index.html` | トップ。ホーム・遊び方・スコアの決まり方・ギャラリーを1画面ずつ切り替える。利用規約などへのリンクはギャラリーの下 |
| `login.html` | ログイン方法の選択と表示名の入力 |
| `lobby.html` | ロビー。ルームコード・参加者・対戦設定 |
| `play.html` | 対戦。お題・プロンプト入力・生成履歴・提出 |
| `result.html` | 結果発表 |
| `terms.html` | 利用規約（仮の文面） |
| `privacy.html` | プライバシーポリシー（仮の文面） |

`common.css`・`common.js`・`transition.css` は画面共通のスタイルと画面遷移、`art.js` は生成画像の代わりに表示するイラストの描画処理です。

## 見方

フォルダで簡易サーバーを起動し、ブラウザで開きます。フォントはGoogle Fontsから読み込むため、インターネット接続が必要です。

```sh
python3 -m http.server 8000
```

`http://localhost:8000/` を開くとトップが表示されます。「スタート」からログイン・ロビー・対戦・結果の順に進めます。

トップはホイール・スワイプ・上下キーで1画面ずつ切り替わります。切り替えの判定は[fullPage.js](https://github.com/alvarotrigo/fullPage.js) 2.9.7と同じ方式です。

`http://localhost:8000/index.html?scroll` を開くと、スクロールロックなし版になります。全セクションを縦に並べて普通にスクロールし、ヘッダーの下線と左上のロゴはスクロール位置に合わせて切り替わります。Figmaでは「draft」ページの「12 ホーム（スクロールロックなし）」が対応します。

## モックの前提

- 生成画像はモックです。プロンプトの言葉から髪の色・髪型・目・服・表情・背景を決めてSVGで描き、お題との一致度を再現度として表示します。
- スコアの計算式は仮です。再現度に、提出速度の加点（最大20）と生成回数の加点（1回で15、1回増えるごとに-3）を足しています。
- ログイン・ルーム・対戦相手の動き・SNS共有は画面上の疑似的な動作で、サーバーとは通信しません。
- 画面の仕様は本体リポジトリの `docs/product.md` を正とします。
